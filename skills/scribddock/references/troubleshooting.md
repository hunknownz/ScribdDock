# 按失败阶段排查

先确定执行的是 ScribdDock 还是原 Python 下载器，记录 OS/架构、Node/pnpm、锁定 SDK、guest/保存会话模式、脱敏错误和输出位置。不要为了收集版本把全部环境变量、请求头或 URL 中的令牌输出到日志。

| 现象 | 有依据的检查和处理 |
| --- | --- |
| `Failed to spawn: scribd-downloader` | 这是原 Python 命令入口。定位 TS checkout 后用其 `pnpm dev --help`；不要反复安装同名 Python 包。 |
| Camoufox 内核缺失或不兼容 | 使用该 checkout 的 `pnpm browser:install`，由锁定官方 SDK 选择兼容内核。不硬编码可执行文件或混用 Python SDK 缓存。安装器遇 API 限流时按 README 处理，不反复强制下载。 |
| 浏览器 UI 乱码且没到登录页 | 查启动/导航错误和当前实现是否使用宿主 OS、`en-US` locale；当前适配器已经配置这些参数。不能仅凭截图断言是字体或 profile 损坏；先保留 profile，用已有浏览器测试或独立临时 profile 复现启动，不直接重置用户会话。 |
| 已按 Enter，但再次提示登录 | Enter 只表示保存会话。检查下载是否误用了 `--guest`、是否仍使用同一个 `SCRIBDDOCK_PROFILE_DIR`，再在 Camoufox 中人工登录。没有账号状态证据时报告“会话已保存，登录状态尚未验证”。 |
| profile 占用或权限错误 | 确认同一 profile 没有另一个活动会话；只关闭属于本次操作的会话。POSIX 是 `0700`，Windows 继承 NTFS ACL。明确重置请求才先备份目录；不删除锁文件来强行并发。 |
| 页面初始化超时、403、验证码 | 查看 `navigation`/`initialization` 阶段和页面是否允许访问。需要用户在可见窗口处理登录或验证码；不重复高速请求或绕过权限。 |
| 字体、图片、批次加载失败 | 保留脱敏资源类别与页码，检查连接及页面变化。字体等待有界，失败应中止；不跳过字体校验或默认允许空白页。 |
| PDF 空白、裁切、页数不符 | 查 `render`/`export`/`print`/`output` 阶段，读项目 PDF 导出文档。比较阅读器预期页数、实际 PDF、文字与逐页渲染；不能只检查文件大小。失败时保护原输出，不用截图拼接掩盖原因。 |
| Windows 导出失败 | 当前 Windows x64 使用同一 Camoufox 的本机 Marionette `WebDriver:Print` 后端，其他平台使用 `window.print()`。查看项目 Windows 指南和传输错误，不自动退回另一个后端、Chromium 或第三方打印程序。 |
| PDF 无法选择/复制文字 | 先判断阅读器本身是文字还是扫描图片。文字文档可独立提取文字，再用 PDF 查看器检查选择和复制；提取成功不等于人工体验已验收。扫描件不属于文字层回归，不擅自增加 OCR。 |
| 路径/输出错误 | 引用带空格的路径，检查父目录、磁盘空间和文件是否被查看器占用；Windows 避开保留文件名。不要通过删除既有 PDF 或改变系统权限掩盖错误。 |

完成有依据的处理后，最多重试一次相同下载；错误重复且没有新的可检验假设时停止，说明失败阶段、已做的检查和缺少的证据。新的明确假设可做小范围诊断，避免反复下载同一大文档。

## 复刻程度的证据边界

以当前 checkout 的 `docs/PARITY_AUDIT.md`、`docs/WINDOWS.md` 和 CI 为准，不给未经定义的“100%”或进度百分比。区分：固定参考样例、模拟/离线测试、实际浏览器、真实公开文档、保存会话复用、受限文档和人工视觉检查。

已有公开 5/20 页和 Windows 公开 5 页证据，不代表所有内容或订阅权限已经验证。SlideShare/Everand/Fable 未实现不属于原 Scribd 下载器的功能退步，而是项目后续范围。语言差异不是默认故障归因；先对照主世界脚本、字体/图片等待、打印后端和页框校正。
