# 路线图

## v0.1：TypeScript CLI

- [x] 全新 Git 历史和 ScribdDock 项目名称。
- [x] TS、Node、pnpm 锁文件、类型检查、格式检查和 CI。
- [x] 来源能力目录、精确路由和 Markdown 链接规范化。
- [x] 独立 Scribd 来源适配器与 Camoufox 浏览器适配器。
- [x] 手动登录、持久化 profile 和游客模式。
- [x] 页面分批加载、专用字体注册、原生打印保留文本层、Quartz 页框修复、校验后替换输出。
- [x] 来源、模拟浏览器、PDF 输出保护和依赖边界测试。
- [x] 默认跳过的真实联网验证入口。

单元/模拟测试、真实联网运行和视觉完整性审核分别记录。

## 下一阶段

SlideShare 优先研究允许下载的原文件流程，确认登录、权限、格式与完整性，通过真实授权样例验证后实现独立适配器。

Everand、Fable 先核实可导出的内容和平台授权。不承诺所有书籍、音频均可下载，不移除 DRM。

## 暂不建设

不增加 Scribd 家族以外来源，也不提前增加 Web UI、数据库、分布式任务系统或模型调用。
